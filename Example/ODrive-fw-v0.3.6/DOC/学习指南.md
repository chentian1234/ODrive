### 4.5 中断触发流程

```
PWM定时器计数到中心点
       ↓
触发ADC注入转换（TIM1触发M0，TIM8触发M1）
       ↓
pwm_trig_adc_cb() 回调函数 [low_level.c 第977行]
       ↓
读取ADC值 → 转换为相电流
       ↓
DC_CAL低通滤波（跟踪直流偏移，τ=0.2s，fc≈0.8Hz）
       ↓
osSignalSet(motor_thread) 唤醒电机线程
```

> **双电机复用ADC时序**：
> - 时刻① TIM1向上计数 → ADC2/3注入触发 → 采样M0电流
> - 时刻② TIM1向下计数 → ADC2/3注入触发 → 采样M0 DC_CAL
> - 时刻③ TIM8向上计数 → ADC2/3规则触发 → 采样M1电流
> - 时刻④ TIM8向下计数 → ADC2/3规则触发 → 采样M1 DC_CAL
>
> 一个PWM周期内共8次ADC中断，完成两个电机的电流和偏移采样。

## 五、第4阶段：深入FOC算法核心

### 5.1 FOC_current函数详解（★）

这是整个工程最核心的函数，实现了完整的FOC算法。

```c
bool FOC_current(Motor_t *motor, float Id_des, float Iq_des) {
    // ====== 第1步：Clarke变换（ABC三相→αβ两相静止）======
    // Ia + Ib + Ic = 0，所以只需要测量两相
    float Ialpha = -motor->current_meas.phB - motor->current_meas.phC;
    float Ibeta = one_by_sqrt3 * (motor->current_meas.phB - motor->current_meas.phC);

    // ====== 第2步：Park变换（αβ静止→dq旋转坐标系）======
    float phase = get_rotor_phase(motor);  // 转子电角度θ
    float c = arm_cos_f32(phase);          // cos(θ)
    float s = arm_sin_f32(phase);          // sin(θ)

    // Park变换公式：
    // Id = Iα·cos(θ) + Iβ·sin(θ)
    // Iq = Iβ·cos(θ) - Iα·sin(θ)
    float Id = c * Ialpha + s * Ibeta;
    float Iq = c * Ibeta - s * Ialpha;

    // ====== 第3步：电流PI控制 ======
    float Ierr_d = Id_des - Id;  // d轴电流误差
    float Ierr_q = Iq_des - Iq;  // q轴电流误差

    // PI控制器：V = Kp·e + Ki·∫e（积分分离实现）
    // 积分项直接存储在 ictrl->v_current_control_integral_d/q 中
    float Vd = ictrl->v_current_control_integral_d + Ierr_d * ictrl->p_gain;
    float Vq = ictrl->v_current_control_integral_q + Ierr_q * ictrl->p_gain;

    // ====== 第4步：调制饱和处理（抗积分饱和）======
    // 检查调制指数是否超过允许范围
    // mod_scalefactor < 1.0f 表示过调制
    float mod_scalefactor = 0.80f * sqrt3_by_2 / sqrtf(Vd*Vd + Vq*Vq);

    if (mod_scalefactor < 1.0f) {
        // 过调制：按比例缩小电压矢量，衰减积分器
        Vd *= mod_scalefactor;
        Vq *= mod_scalefactor;
        ictrl->v_current_control_integral_d *= 0.99f;  // 缓慢衰减
        ictrl->v_current_control_integral_q *= 0.99f;
    } else {
        // 正常情况：更新积分器
        ictrl->v_current_control_integral_d += Ierr_d * ictrl->i_gain * dt;
        ictrl->v_current_control_integral_q += Ierr_q * ictrl->i_gain * dt;
    }

    // ====== 第5步：反Park变换（dq旋转→αβ静止）======
    // 反Park变换公式：
    // Vα = Vd·cos(θ) - Vq·sin(θ)
    // Vβ = Vq·cos(θ) + Vd·sin(θ)
    float mod_alpha = c * Vd - s * Vq;
    float mod_beta = c * Vq + s * Vd;

    // ====== 第6步：SVM调制 → 计算PWM占空比 ======
    queue_modulation_timings(motor, mod_alpha, mod_beta);

    return true;
}
```

### 5.2 坐标系变换图解

```
 Clarke变换          Park变换
ABC坐标系  →→→   αβ静止坐标系  →→→   dq旋转坐标系
(三相交流)      (两相交流)         (两相直流)
                                      ↑
                                 好处：
                                 交流变直流
                                 PI控制无静差
```

### 5.3 SVM空间矢量调制

```
目的：将Vα、Vβ转换为三相PWM占空比(tA, tB, tC)

原理：
- 三相逆变器有8种开关状态（2^3）
- 6个有效矢量 + 2个零矢量
- 通过伏秒平衡原理合成目标电压矢量

扇区判断（6个扇区）：
        V3(010)
          |
    V2(110)---V4(011)
         \ | /
    ------O------  α轴
         / | \
    V1(100)---V5(001)
          |
        V6(101)
```

## 九、安全注意事项

### 上电前检查

1. **确认电机参数**：极对数(pole_pairs)、编码器分辨率(encoder_cpr)必须正确
2. **确认电流限制**：current_lim不要设置过大，建议从5A开始
3. **确认接线**：三相线序、编码器接线、电源极性
4. **固定电机**：调试初期请将电机固定在台面上，防止失控甩出

### 急停操作

- 串口命令：`h` （所有电机立即停止）
- 硬件方式：断开电源或按下急停按钮

### 调试建议

1. **先低电流**：初始测试时电流限制设为5A以下
2. **先编码器模式**：无感模式需要精确的磁链参数，先用编码器模式验证电机
3. **逐步加速**：速度从小到大逐步增加，不要直接给高速
4. **观察电流**：通过串口或调试器实时观察相电流波形

## 十一、总结

**学习FOC的核心要点**：

1. **理解坐标系变换**：ABC→αβ→dq的物理意义
2. **掌握三环控制**：位置环→速度环→电流环的级联
3. **搞清执行流程**：从main()到FOC_current()的调用链
4. **动手调参**：理论结合实践，观察参数影响

**M0与M1的默认配置差异**：
- M0默认使用 `CTRL_MODE_VELOCITY_CONTROL`（速度控制）
- M1默认使用 `CTRL_MODE_POSITION_CONTROL`（位置控制）
- 两者极对数、磁链等参数相同，但增益值有差异

**代码中已知问题**：
- `freertos.c` 第182行：`osSemaphoreWait(sem_usb_irq, 0)` 应为 `osSemaphoreWait(sem_usb_rx, 0)`，这是一个明显的笔误。
